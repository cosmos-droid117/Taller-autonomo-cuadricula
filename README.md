# Taller-autonomo-cuadricula - Guia de instalación

1. Debe contar con un IDE para ejecutar el código, para ello es recomendable descargar e
instalar Intellij ya que permite cargar la carpeta del proyecto sin necesidad de instalar algo adicional dentro del IDE
2. Instalar la última versión del JDK (Java Development Kit), de lo contrario el código no podrá compilarse
3. Descargar la carpeta en formato .zip desde Github
4. Descomprimir el archivo .zip
5. Abir Intellij y en el menú principal, debe dar clic en el boton "Open" y seleccionar la carpeta previamente descomprimida, esto cargara el proyecto en el IDE 
6. Busca la carpeta llamada "src" desde el menu lateral izquierdo llamado "Project" y dale clic, dejándote ver las clases que el programa contiene
7. Selecciona el archivo "Main" y ejecútalo con el boton "Run 'Main.java'" ubicado en el menú superior del IDE.

A partir de aquí, deberás prestar atención a los textos que se entrguen por conosla para que el programa siga su curso
